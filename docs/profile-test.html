Test onboard profile switching

Close the main editor tab before connecting here. This test is for the wired HE68 Pro MK922, firmware 1.16 / frame version 0. It tests hardware slots; it does not install your named browser profiles into them.

  1. Connect and note the reported slot number.
  2. Install the two test shortcuts. The current Fn map is backed up first.
  3. Press Fn + Delete, then click Read active slot. An increase from 0 to 1 would confirm the second slot.
  4. If Fn + Insert does not return you to slot 0, install the shortcuts in the new slot too, then press Fn + Insert and read again.
  5. Use Restore this slot's Fn map in each modified slot when done.

The test changes only Fn + Insert and Fn + Delete in the active slot. Slot switching may change your active lighting and key settings. Each slot's first backup is kept in this browser and downloaded before any write.
